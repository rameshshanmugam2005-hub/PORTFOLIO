# ⚡ Run Locally

### 1. Clone

```bash
git clone https://github.com/rameshshanmugam2005-hub/PORTFOLIO.git
```

### 2. Enter project

```bash
cd PORTFOLIO
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```

### 5. Build production version

```bash
npm run build
```
